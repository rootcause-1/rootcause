**Project name:** RootCause

**Tagline:** An AI on-call engineer that sees your system as a graph, finds the one real cause behind a storm of

**The problem.** Modern apps are dozens of services calling each other. When one breaks, everything that depends on
it fails too, the monitoring fires an alarm for each one, and several teams get paged. Every alarm is real, but only
one service is the cause. Finding it by hand is the slowest part of every outage.

**What it does.** RootCause watches the official OpenTelemetry Demo shop. Every 5 seconds it turns live traces,
metrics, container restarts and feature-flag changes into one FalkorDB graph, together with the shop's code from
GitHub (modules, gRPC APIs, declared dependencies, flag reads). When something breaks it:
1. groups the alarms into one incident (`algo.WCC` over BLAMES edges),
2. ranks the suspects (depth, own errors, `algo.pageRank`, recent change, memory) and proves the answer with the
   shortest BLAMES path,
3. lets a Gemini agent investigate through 16 MCP tools (every call is a graph query, saved as a `Step` node),
4. proposes the safest fix with its blast radius (`algo.bfs`) and risk (`algo.betweenness`), and acts only after a
   person approves,
5. verifies that every alarm clears, writes the report, remembers the incident (Jaccard over signal patterns),
6. and can open the code fix as a GitHub pull request written by Gemini, with the graph's evidence in the
   description. A person reviews and merges it.

**How FalkorDB is used.** FalkorDB is the only database and the engine's state: services and calls, baselines,
alerts, incidents, changes, teams and on-call, journeys, code modules and APIs, agent steps, memory, reports and pull
requests are all nodes and edges. 102 named Cypher queries; the algorithms are WCC, PageRank, shortest path, BFS and
betweenness. Without FalkorDB nothing groups, ranks, proves, predicts or remembers.

**Proof.** 15 blind chaos runs on the real demo, scored by code: RootCause named the cause first in 80 % (loudest
alarm 53 %; Gemini with only a flat alarm table 80 %, but it missed the broken connection only the graph could see).
207 tests on a real FalkorDB, 7 golden replays. Live runs opened real pull requests on our fork, merged by a person.

**Blog post (side prize):** draft in docs/BLOG.md.

**Built with.** Python 3.12, FastAPI, FalkorDB v4.22.1, OpenTelemetry Demo + Collector, MCP Python SDK (FastMCP),
Google Gemini, React + Vite + TypeScript + Tailwind, Docker, AWS EC2.

**Data.** Only telemetry generated by the OpenTelemetry Demo on our machines, a synthetic seed file (invented teams,
people, runbooks) and the public OpenTelemetry Demo source code.

**AI disclosure.** We used Claude Code as an AI coding assistant; every module it wrote or changed is listed in
docs/AI_DISCLOSURE.md with what a person verified. RootCause itself uses Google Gemini at runtime. The demo video's
draft narration is the open-source Kokoro-82M voice.
